# Chandrasmit duplex 1204: floor plan and storage designs

An interactive, to-scale planner for duplex flat 1204 (12th and 13th floors, with the mezzanine).

**Live site:** https://apoorvaaj.github.io/ChandrasmitFloorplan/

## What it does

- **Floor plan:** drag, rotate and resize furniture on both floors, with live wall clearances. Switch between cm and ft-in, overlay the original brochure drawing, export an image, or copy a layout to paste back in later.
- **Storage units:** to-scale wall elevations for each built-in unit, with a compartment schedule for the carpenter:
  - 13F walk-in wardrobe
  - 12F store room
  - 12F dry balcony (utility tower, laundry, sink platform)
  - 12F study room (floating altars, puja bench, desk, bookshelf)
  - 12F master bedroom (dressing wall, wardrobe, window seat)
  - 12F guest bedroom wardrobe
  - 13F dressing area
  - 13F wellness storage wall

Open `#storage` on the URL to land on the storage section.

Layouts are saved in each viewer's own browser (localStorage); nothing is sent to a server.

## Hosting

Single self-contained `index.html` (fonts from Google Fonts). GitHub Pages serves it from the `main` branch root.
